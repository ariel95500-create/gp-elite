# The modules of the split, the lower first (layout_core.py checks it).
# A part of core.py goes to the module of its section in the map
# (map_core.py, ROLES), under the file name below where the role's name
# would collide with a name of core.py (simplify, evaluate, fitness) or
# would mislead; unless a "move" line sends it elsewhere.

file simplify simplification             # the simplification of a tree
file evaluate evaluation                 # code generation, compilation, evaluation
file fitness scoring                     # scaling, errors, fitness
file constants fitting                   # the fitting of constants (LM, Adam)
file operators genetic                   # the genetic operators
file selection final_choice              # the final choice of the model

order: core numeric config tree simplification evaluation datasets scoring fitting genetic memory final_choice seeds islands parallel search data console
